How to fill this in

A few seconds of detail here makes the generated content much better. Here's what each field is for.

Client
Who the content is for. Used to label and filter work on the dashboard. e.g. Acme Co
Topic
The one subject of the content, in plain words. It becomes the title and the spine of every script, so keep it to a single clear idea. e.g. how solar panels work
Keywords
Comma-separated, concrete visual words. They're used to search stock footage, so prefer things a camera can show — objects, places, people, actions. Good: solar panel, rooftop, sunrise, technician Avoid: efficiency, savings, the future
Source URL optional
A link to an article the scripts should be based on. If you add one, we fetch the page and use its main text as the factual source, so the script won't make things up. Leave it blank to let the model write from the topic alone. e.g. https://example.com/solar-guide
Outputs
Tick the deliverables you want — any combination. Text pieces are quick; the videos take longer to render.
Voice
The narration voice used for the reel and long video. Each option notes its accent and tone.
Long video length
Roughly how long the long video should run. It sets how many narration chapters the script has (about one minute each), so a longer pick means a longer video. The reel always stays ~60s. Longer videos take more time to render.
Description optional
Anything else that should steer the writing: tone, target audience, must-mention points, or a rough draft. It's sent to the model alongside the topic and source article. e.g. casual tone, target homeowners, mention government rebates
